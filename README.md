# INSPECTAMX — demo visual

Sitio de producto en GitHub Pages:

**[https://lalostatic.github.io/INSPECTA-1.2/](https://lalostatic.github.io/INSPECTA-1.2/)**

El producto se llama **INSPECTAMX**. Esta URL se mantiene porque ya se comparte con clientes.

El patio en operación (login, cámara, Postgres) está en el código de **[github.com/lalostatic/INSPECTAMX](https://github.com/lalostatic/INSPECTAMX)**.  
`inspectamx.com` es el dominio previsto; hoy no tiene DNS.

Esta página es el folleto: capturas de contenedor, plano de chasis, M&R y pintura. No pide contraseña y no corre la aplicación.

## Qué ve un cliente aquí

- Inspección de **contenedor** con mapa de puntos (puertas, interior, laterales). Toque → cámara.
- Inspección de **chasis** sobre plano técnico (elevación, planta, frente, trasera). No es inspección de vehículo.
- Taller M&R y pintura según el **ingreso diario** al patio, no un pipeline fijo.
- Capacidad de referencia: pintura 5–7 contenedores/día, M&R ~12 unidades/día.
- Un patio por empresa. Acceso solo con correo y contraseña. Sin alta pública.

## Qué ya no se muestra

- Alta pública o “crear cuenta”.
- Cloudflare Workers / D1 como el sistema del patio.
- El nombre INSPECTA 1.2 como marca (solo queda en la URL).
