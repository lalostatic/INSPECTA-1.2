El código actual es **[github.com/lalostatic/INSPECTAMX](https://github.com/lalostatic/INSPECTAMX)**.

GitHub Pages es el folleto: capturas de contenedor, plano de chasis, M&R y pintura. No corre la aplicación.

## Qué muestra esta demo

- Inspección de **contenedor** con mapa de puntos (puertas, interior, laterales).
- Inspección de **chasis** sobre plano técnico (no es inspección de vehículo).
- Taller M&R y pintura según el **ingreso diario** al patio.
- Capacidad de referencia: pintura 5–7 contenedores/día, M&R ~12 unidades/día.
- Acceso solo con correo y contraseña. Sin alta pública.
